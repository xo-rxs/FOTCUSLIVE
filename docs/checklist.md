## 회귀 점검표

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
| --- | --- | --- | --- | --- |
| 준비 | 점검 환경 | README의 실행 방법으로 서버를 켠다. 같은 와이파이에 휴대폰 두 대와 시청용 브라우저를 연결한다. 라이브 점검에는 휴대폰에서 신뢰하는 HTTPS 주소를 사용한다. 선수가 이동하고 한동안 가려지는 축구 경기 장면을 촬영할 수 있게 준비한다. | 서버 첫 화면이 열리고 두 휴대폰과 시청용 브라우저에서 같은 서버 주소에 접속할 수 있다. | |
| 사전 | 콘솔·서버 오류 없음 | 서버 컴퓨터와 시청용 브라우저의 개발자 도구에서 콘솔 메시지를 지운다. 앱을 새로고침하고 아래 ①부터 ⑩까지 수행하면서 콘솔과 서버 로그를 확인한다. | 새로고침과 점검 과정에서 브라우저 콘솔 오류 및 서버 오류 로그가 없다. | |
| ① | 촬영방 만들기 | 첫 번째 휴대폰에서 **새 촬영방 만들기**를 누르고 화면의 촬영방 코드와 기기 번호를 적는다. | 여섯 자리 코드가 표시되고 첫 번째 휴대폰이 `1번 촬영 기기`로 나타난다. | |
| ②-1 | 승인 전 다른 기기 차단 | 시청용 브라우저에서 ①의 촬영방 코드를 입력해 참여를 요청하되 첫 번째 휴대폰에서는 확인번호를 승인하지 않는다. 두 휴대폰의 연결 상태를 확인한다. | 시청용 브라우저에는 확인번호와 승인 대기가 표시되고, 촬영방의 2번 기기는 여전히 `연결 대기 중`이다. | |
| ② | 두 번째 휴대폰 연결 | 두 번째 휴대폰에서 ①의 코드를 입력한다. 그 화면에 표시된 확인번호를 직접 보고 첫 번째 휴대폰의 **기기 연결 승인** 칸에 입력한다. | 두 번째 휴대폰만 `2번 촬영 기기`로 연결되고, 두 화면에서 1번·2번 기기의 연결 상태가 표시된다. ②-1의 시청용 브라우저는 촬영 기기로 연결되지 않는다. | |
| ③ | 두 기기 촬영·저장 | 각 휴대폰에서 **지금 촬영**을 눌러 축구 장면을 촬영하고 등록한다. 브라우저가 촬영 화면을 제공하지 않으면 휴대폰 카메라로 촬영한 영상을 **저장된 영상 선택**으로 등록한다. 두 기기의 분석이 끝날 때까지 기다린다. | 1번·2번 기기가 각각 `영상 준비 완료`로 표시되고 서버의 `data/<촬영방 코드>/device-1/video.mp4`와 `data/<촬영방 코드>/device-2/video.mp4`가 존재한다. | |
| ④ | 저장 영상 열기·선수 선택 | **1번 기기 영상 보기**를 누른다. 원본 영상에서 선수 표시가 나타나는 시각으로 이동한 뒤, 움직이는 선수 한 명의 표시 안쪽을 누른다. | 저장된 영상이 열리고 선택한 선수의 번호와 따라보기 안내가 나타난다. | |
| ⑤ | 재생 중 선수 따라가기 | ④에서 선수를 선택한 상태로 **재생**을 누르고 선수가 이동하는 구간을 본다. | 확대 화면이 선택한 선수의 움직임을 따라 이동한다. | |
| ⑥ | 추적 끊김과 재선택 | 선택한 선수가 가려지거나 화면 밖으로 나가는 구간까지 재생한다. 전체 경기 화면에서 다시 보이는 선수의 표시를 누른다. | 추적이 끊기면 확대 화면 대신 전체 화면 복귀·재선택 안내가 나타나고, 다시 선택하면 따라보기를 시작할 수 있다. | |
| ⑦ | 라이브 시작 | 촬영방에 연결된 첫 번째 휴대폰에서 **라이브 시작**을 누르고 카메라 권한을 허용한다. | 카메라 미리보기와 `라이브 중` 상태가 표시된다. | |
| ⑧ | 시청 가능한 방 표시 | 시청용 브라우저에서 **라이브 방 보기**를 열고 목록을 확인한다. | 방송 중인 라이브 방이 목록에 나타난다. 목록에는 촬영방 코드 대신 임시 라이브 식별자가 표시된다. | |
| ⑨ | 현재 경기 라이브 시청 | ⑧의 라이브 방을 누른다. 재생 버튼이 나타나면 누른 뒤 첫 번째 휴대폰 카메라 앞에서 사람이나 공을 움직인다. | 시청 화면에서 현재 카메라 장면의 움직임이 이어서 보인다. 시청용 브라우저는 촬영방의 2번 기기 자리를 차지하지 않는다. | |
| ⑩ | 라이브 종료 | 첫 번째 휴대폰에서 **라이브 종료**를 누른 뒤 시청 화면과 라이브 방 목록을 확인한다. | 시청 영상이 종료되고 해당 라이브 방이 목록에서 사라진다. | |
