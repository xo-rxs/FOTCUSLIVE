# 앱 기획서

## 1. 앱 이름

FOTCUSLIVE

## 2. 사용자 (누가 쓰나)

나의 멋진 플레이를 녹화하고 따라가면서 돌려보고 싶을떄, 내가 좋아하는 선수만 따라가며 가까이 보고싶을때

## 3. 해결할 문제 (왜 필요한가)

보통의 축구경기 라이브는 직접 카메라를 확대하고 있어야 하는데, 이 앱은 ai가 직접 화면을 보며 추적해줌.

내 지리는 플레이를 추적해서 찍으면 놓칠 일이 없음

## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)

꼭 필요한 기능 (첫 버전)

- 두 휴대폰을 연결해 두 휴대폰 모두 축구 경기를 촬영하고 영상을 저장한다.
- 촬영한 영상에서 보고 싶은 선수를 직접 선택한다.
- 선택한 선수를 AI가 추적하고, 재생 화면이 그 선수를 따라 확대·이동한다.
- 선수가 가려지거나 촬영 범위 밖으로 나가 추적이 끊기면 전체 경기 화면으로 돌아가고 다시 선택할 수 있게 안내한다.

있으면 좋은 기능 (이후 버전)

- 골 장면 스크랩, 하이라이트 자동 추출, 히트맵, 선수 활동 기록.

## 5. 화면 구성 (위에서 아래 순서)

1. 앱 이름과 촬영 시작 안내.
2. 두 휴대폰의 연결 상태와 각각의 촬영 상태.
3. 촬영 시작·종료 버튼.
4. 촬영한 경기 영상 목록과 재생 화면.
5. 화면 속 선수 선택 및 선수 따라보기 기능.
6. 추적이 끊겼을 때 전체 화면 전환 안내와 선수 재선택 버튼.

## 6. 사용 흐름 (사용자가 하는 행동 순서)

두 휴대폰을 준비한다 → 앱에서 두 휴대폰을 연결한다 → 두 휴대폰으로 축구 경기를 촬영한다 → 촬영을 마치고 저장된 영상을 연다 → 화면 속에서 보고 싶은 선수를 선택한다 → 선택한 선수를 따라 확대·이동하는 영상을 본다. 추적이 끊기면 전체 경기 화면에서 선수를 다시 선택한다.

두 휴대폰으로 촬영하는 방식의 참고 제품: [Veo](https://www.veo.com/).

## 7. 만들지 않을 것

첫 버전에서는 골 장면 스크랩, 하이라이트 자동 추출, 히트맵, 선수 활동 기록, 실시간 송출을 만들지 않는다.

## 8. 완료 기준

1. 두 휴대폰 모두 연결 상태를 확인하고 경기를 촬영·저장할 수 있다.
2. 저장된 축구 경기 영상을 열어 선수 한 명을 선택할 수 있다.
3. 영상 재생 중 확대 화면이 선택한 선수를 따라 이동한다.
4. 선수가 가려지거나 화면 밖으로 나가 추적이 끊기면 전체 화면으로 돌아가고 재선택 안내가 나타난다.

## 후속 단계: 경기 라이브

첫 버전의 촬영·업로드·분석 흐름에 이어, 한 촬영방에서 한 기기가 카메라 영상을 라이브로 송출한다. 시청자는 별도의 라이브 방 목록에서 방송 중인 경기를 선택해 본다. 시청은 촬영 기기 자리를 사용하지 않는다.

1. 촬영방에서 라이브를 시작하고 종료할 수 있다.
2. 방송 중인 방이 시청 화면 목록에 나타난다.
3. 시청자가 현재 카메라 영상을 재생할 수 있다.

이 단계의 라이브 영상은 저장하거나 선수 추적 분석을 하지 않는다. 휴대폰 카메라 송출에는 HTTPS 연결이 필요하다.
