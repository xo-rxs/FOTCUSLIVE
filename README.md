## 1. 앱 이름과 한 줄 소개

**FOTCUSLIVE(포커스라이브)**는 두 휴대폰으로 축구 경기를 촬영하고, 영상에서 고른 선수를 확대해 따라보는 앱입니다.

## 2. 누구를 위한 앱인가

자신의 축구 경기를 다시 보고 싶은 사람과 좋아하는 선수 한 명을 가까이 보고 싶은 사람을 위한 앱입니다.

## 3. 할 수 있는 일

- 촬영방을 만들고, 확인번호로 두 번째 휴대폰의 연결을 승인할 수 있습니다.
- 두 휴대폰에서 각각 영상을 촬영하거나 저장된 영상을 등록할 수 있습니다.
- 분석된 영상에서 선수를 고르면 확대 화면이 그 선수를 따라갑니다. 추적이 끊기면 전체 화면에서 다시 고를 수 있습니다.
- 한 기기에서 카메라 영상을 라이브로 보내고, 다른 브라우저에서 시청할 수 있습니다.

## 4. 사용 방법

1. 첫 번째 휴대폰에서 **새 촬영방 만들기**를 누르고 여섯 자리 코드를 확인합니다.
2. 두 번째 휴대폰에서 코드를 입력합니다. 두 번째 휴대폰의 확인번호를 첫 번째 휴대폰에 입력해 연결을 승인합니다.
3. 각 휴대폰에서 **지금 촬영** 또는 **저장된 영상 선택**을 눌러 영상을 등록합니다. 분석이 끝날 때까지 기다립니다.
4. 기기 영상을 열고 원본 화면에서 선수 표시를 누릅니다. 영상을 재생하면 확대 화면이 선수를 따라갑니다. 놓치면 전체 화면에서 다시 선택합니다.
5. 라이브로 보여 주려면 연결된 기기에서 **라이브 시작**을 누릅니다. 시청자는 **라이브 방 보기**에서 방송을 선택합니다.

## 5. 실행 방법

Python 3.10 이상과 `ffmpeg`가 필요합니다. `ffmpeg -version`으로 설치 여부를 확인하세요.

macOS 또는 Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

Windows PowerShell:

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

컴퓨터에서 `http://localhost:8000`을 엽니다. 두 휴대폰을 컴퓨터와 같은 와이파이에 연결하고, 휴대폰에서는 컴퓨터의 와이파이 주소로 접속합니다. 예를 들어 컴퓨터 주소가 `192.168.0.10`이면 `http://192.168.0.10:8000`을 엽니다.

휴대폰 카메라로 라이브를 시작하려면 휴대폰이 신뢰하는 HTTPS 주소가 필요합니다. 로컬에서는 [mkcert](https://github.com/FiloSottile/mkcert)를 설치하고, 아래 주소를 실제 컴퓨터 주소로 바꿔 인증서를 만듭니다.

```sh
mkdir -p certs
mkcert -install
mkcert -cert-file certs/local.pem -key-file certs/local-key.pem 192.168.0.10 localhost 127.0.0.1
.venv/bin/python -m uvicorn server:app --host 0.0.0.0 --port 8000 --ssl-certfile certs/local.pem --ssl-keyfile certs/local-key.pem
```

휴대폰에도 `mkcert -CAROOT`에 있는 `rootCA.pem`을 설치하고 신뢰 설정을 켠 뒤 HTTPS 주소로 접속합니다. `rootCA-key.pem`은 공유하지 마세요.

## 6. 확인 방법

[회귀 점검표](docs/checklist.md)에 따라 촬영방 생성(①), 두 번째 휴대폰 연결(②), 영상 저장(③), 선수 선택과 따라보기(④~⑤), 추적이 끊겼을 때 재선택(⑥)을 확인합니다. 라이브는 시작·시청·종료(⑦~⑩)를 확인합니다. 브라우저 콘솔과 서버 오류도 함께 확인합니다.

## 7. 데이터 저장 안내

촬영 영상과 분석 결과는 서버 컴퓨터의 `data/`에 저장됩니다. 이 폴더는 Git에 포함하지 않습니다. 촬영방 코드를 아는 같은 네트워크 사용자는 영상을 볼 수 있으므로 신뢰할 수 있는 네트워크에서 사용하세요. 첫 분석 때는 추적 모델 파일을 내려받습니다.
